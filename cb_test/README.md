# 耳溫槍 CB(ACK) 流程測試工具

獨立於主專案的單槍測試工具，用來驗證客戶文件的正常握手流程 **CD → DB → CB**，
以及釐清「CB(ACK) 到底需不需要送」（主程式從未送過 CB）。

## 環境需求
- Windows + Python 3（只用標準函式庫，無需安裝套件）
- 一支已和本機完成藍芽配對的耳溫槍，且知道其 MAC 位址

## 執行
```
python test_cb_flow.py 00:18:E4:34:D2:1A
```
或直接執行 `啟動CB測試.bat`（會提示輸入 MAC）。

## 互動指令
| 指令 | 作用 |
|---|---|
| `cd` | 送出 CD（主動要求量測） |
| `cb` | 手動送一次 CB（ACK） |
| `cbon` | 開啟「收到 DB 自動回 CB」（預設開，符合規格） |
| `cboff` | 關閉自動 CB（測試不回 ACK 槍會不會卡住） |
| `stat` | 顯示統計（收到 DB / 送出 CB / 送出 CD 數） |
| `q` | 離開 |

## 建議測試步驟
1. **驗證正常握手**：預設自動 CB 開。實體按壓槍數次，確認每次 DB 後都成功回 CB、槍持續正常回報。
2. **驗證 CB 是否必要**：輸入 `cboff` 關掉自動 CB，連續按壓多次：
   - 若數次後槍**停止回應** → CB 是必要的（主程式需補送 CB）。
   - 若仍**照常回報** → CB 可省略（主程式不送 CB 沒問題）。
3. **驗證 CD 主動量測**：槍閒置時輸入 `cd`，觀察是否回 DB。

所有送收都會以時間戳 + 原始 hex 印出，方便比對協定。
